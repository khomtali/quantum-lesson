# quantum lesson

атмосферный react-прототип сайта с уроками по квантовой механике.

## что внутри

- урок 1: как физика дошла до квантовой механики
- урок 2: каркас про интерпретации и философские следствия
- мини-словарь
- блок быстрых вопросов

## локальный запуск

```bash
npm install
npm run dev
```

## production preview

```bash
npm run build
npm run preview
```

## github pages

после push в `main` сайт деплоится через github actions.
